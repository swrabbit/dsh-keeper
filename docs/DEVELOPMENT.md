# DSH 管家 · DSH Keeper

`dsh-keeper` — a DeepSeek Harness plugin that puts workspace-session,
plugin, sidebar-entry and notification management in one place. 一个带左侧栏
入口的 DSH 插件：集中管理工作区会话（含删除/回收站）、插件、侧栏入口与通知。

## 功能

- **侧栏入口**：左侧栏底部面板列表新增「DSH 管家」图标，点击在工作区主区打开管理页。
  管理页标签依次为「会话管理 / 插件管理 / 回收站 / 通知管理」。
- **会话总览**：按工作区分组列出会话（标题、最后活动、消息数、占用、运行/归档/空会话徽标），
  支持搜索、按活动/大小/标题排序（下拉为宿主风格样式）、当前工作区高亮、8 秒自动刷新。
- **三段式删除**：
  - 归档：从侧栏隐藏，可随时取消归档（不移动磁盘文件）。
  - 回收站：把会话日志目录移入插件自己的回收站，可恢复、可彻底删除。
  - 彻底删除：二次确认（默认焦点在「取消」，Esc 关闭），显示标题、工作区与可释放空间；
    运行中的会话禁止删除。
- **批量与加分项**：批量选择/批量归档/批量移入回收站、删除后 5 秒撤销 toast、
  清理空会话、「空间占用排行」Top 5（按会话日志大小排序，带序号，前三名红/橙/黄高亮，
  点击标题或「选中」加入批量操作）、侧栏预设（精简/全部显示）、入口名称冲突提示、
  删除前导出会话日志、回收站清空。
- **侧栏显示开关**：集中列出当前可管理的面板入口（内置插件 / 市场 / 计划任务 / 第三方），
  每项显示该面板自己注册的图标；开关即时生效并持久化；只隐藏入口、不停用插件本体。内置插件入口始终显示。
- **设置页**：设置 → DSH 管家，含默认删除行为、彻底删除二次确认开关、
  入口显示、恢复默认、关于（版本与数据路径），全部使用 `--dsw-alias-*` 主题 token，
  light/dark 自动跟随；页面配色、字号与间距对齐官方设置页，左侧导航图标与侧栏入口一致，
  切换面板/加载时使用与主程序一致的短淡入动效。
- **本地化**：中/英双语界面与插件元数据，原创 SVG 图标；跟随主程序语言自动切换。

## 安装

在 DSH 插件管理器中安装本目录（或执行等价的 `plugin_manager install_bundle`），
插件会以 bundle 形式并入当前 profile：Host 半边提供一个本机数据 API，Client 半边由
Web UI 模块加载器装载。

## 数据与安全

- 从旧版本升级：首次加载会自动把旧数据目录、回收站元数据和界面偏好迁移到
  `dsh-keeper`，旧目录保留一版作为回退。
- 插件状态：`~/.dsh/storages/dsh-keeper/state.json`
  （侧栏隐藏项与设置）。
- 回收站：`~/.dsh/storages/dsh-keeper/trash/<trashId>/`，条目元数据
  `.dsh-keeper-trash.json` 记录原路径、工作区与大小。
- 会话日志：`~/.dsh/sessions/<工作区 slug>/session-<uuid>/session.v4.jsonl.zstd`。
- 删除先由 Host 侧 `workspaceRegistry.archiveSession`/`detachSession` 停止并解绑活动，
  再把日志目录移入回收站；恢复时移回原路径并重新挂回工作区。
- 所有 API 只接受本机同源 POST，并经过 `ctx.connection.requestRejection` 信任栅栏。

## 设计说明

当前 DSH 版本内置的「面板 pin/unpin」只保存在内存中（刷新即重置），也没有对外的
pin 服务，因此侧栏入口的持久化开关由本插件自己的状态 + 客户端样式隐藏实现；
隐藏只影响入口按钮，不会停用任何插件。升级 Host 后若出现官方持久化接口，可在
`client.js` 的 `applyHide` 处替换实现。
